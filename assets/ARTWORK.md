# Simple Hulk game artwork

Generated with the built-in imagegen tool. Final atlases are stored only in this directory. The existing book covers remain in output/pdf; these are new game assets in the same grayscale pencil / ink family. No API-key CLI was used.

The renderer samples equal atlas cells directly, preserving their transparent backgrounds, and applies a grayscale display filter. No project files reference the generation tool's original save locations. The Marine refinement is the authoritative playable crew set: overhead idle/left/right poses, with one weapon per column. Earlier crew cells in hulk-atlas are supplemental illustrations.

All sprites use a 32 by 32 logical cell. The generated source cells have higher resolution so zooming preserves the pencil detail. Four quarter-turn facings are rendered from each pose, with the source-art heading recorded for bugs.
